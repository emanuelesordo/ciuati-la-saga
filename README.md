# Ciuati – La Saga

Piattaforma cloud per la saga a fumetti generata con AI.

## Infrastruttura
- Frontend: Next.js su Vercel
- Database, Auth e Storage: Supabase (eu-central-1)
- Codice e versionamento: GitHub

## Stato
Repository inizializzato. Migrazioni database e frontend ancora da sviluppare, verificare e distribuire.

## Sicurezza
Le chiavi di servizio e le credenziali non devono essere salvate nel repository. I contenuti privati dei personaggi non devono essere pubblicati senza approvazione.
