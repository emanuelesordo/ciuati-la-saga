# UI game-first

Regola globale per tutte le pagine presenti e future: mobile-first, contenuti prioritari, titoli e spazi compatti, navigazione persistente accessibile, tab per categorie, interazioni da videogioco fantasy-fumettistico. Preservare dati, permessi e accessibilità. Verificare build, responsive e deployment prima di dichiarare concluso.

## Intestazioni con categorie
Titolo centrato il più in alto possibile; tab centrate subito sotto, senza sottotitoli ingombranti. Su mobile mantenere scorrimento orizzontale delle tab se necessario. Le card dei personaggi usano etichette brevi per il gruppo e una sola freccia decorativa per indicare apertura; l'intera card resta un link accessibile.
